# AMMA SOLAR

Bilingual (Marathi default + English) solar marketing site for Nashik — Next.js 15, Tailwind, next-intl. Deploy free on Vercel.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (Marathi). English: `/en`.

## Env

Copy `.env.example` to `.env.local`. Leads always open WhatsApp. Set `RESEND_API_KEY` + `LEAD_TO_EMAIL` later for email copies.

## Deploy (Vercel Hobby)

1. Push this repo to GitHub  
2. Import project in Vercel  
3. Set `NEXT_PUBLIC_SITE_URL` to your production URL  
4. Deploy
